# Strings in C

This folder contains programs related to strings in C.

## Topics Covered

1. String Basics
2. String Input
3. String Library Functions
4. String Algorithms

## Concepts Practiced

- Character Arrays
- Null Character (`\0`)
- String Declaration
- String Input using `scanf()` and `fgets()`
- String Length (`strlen`)
- String Copy (`strcpy`)
- String Concatenation (`strcat`)
- String Comparison (`strcmp`)
- Reverse String
- Count Vowels
- Palindrome Check
- Count Words
- Count Uppercase & Lowercase Letters

Language: C
